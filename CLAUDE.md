## Project Overview
Nexter is a web-based quiz platform with multiple game modes:
- Quickplay Fun (open access)
- Quickplay Competitive (auth required, ELO system)
- Competitions/Tournaments (user-created events)

## Tech Stack
- Frontend: Next.js 14+ with TypeScript
- Backend: Node.js with Express/Fastify
- Database: PostgreSQL with Prisma ORM
- Real-time: Socket.IO
- Auth: NextAuth.js
